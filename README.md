# Sistema Web de Gestión de Servicios de Campo (FSM) - Telecomunicaciones

Proyecto de Ingeniería en Sistemas Computacionales.

## Estructura del Proyecto
- `/angular`: Aplicación Frontend (Angular).
- `/nestjs`: API REST y Motor de Ponderación (NestJS).
- `/docs`: Documentación, diagramas y especificaciones del sistema.
- `compose.yaml`: Infraestructura de base de datos en PostgreSQL.
